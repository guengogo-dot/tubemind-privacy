TubeMind AI Privacy Policy

Last updated: August 13, 2026

TubeMind AI is a Chrome extension for inspecting, searching, navigating, copying, and optionally summarizing YouTube video transcripts from a sidebar on YouTube watch pages.

Data TubeMind AI Processes

TubeMind AI may process the following data in the browser:

  • the current YouTube page URL and video ID;
  • YouTube caption metadata and transcript/caption responses for the active video;
  • transcript search queries entered in the extension;
  • optional AI provider settings, including provider endpoint/base URL, model, API key, and external AI consent state;
  • optional AI-generated summary content for the active video/transcript.

How Data Is Used

The data above is used only to provide TubeMind AI's user-facing features, including loading and displaying transcripts, searching transcript text, jumping to timestamps, copying transcripts, and optionally generating an AI summary.

Data Transmission

TubeMind AI does not operate a TubeMind-hosted backend service and does not send transcript content, search queries, browsing history, or personal information to a TubeMind AI server.

The extension may request caption resources from YouTube to load transcripts for the video the user is currently viewing.

Transcript search and normal transcript navigation run locally in the browser extension context.

If the user explicitly configures an OpenAI-compatible provider and grants external AI consent, TubeMind AI sends transcript-derived content required for summary generation directly to the user's configured external provider. The request uses the user-supplied Bearer API key. TubeMind AI does not operate or control that external provider.

Data Storage

AI configuration is stored locally in the browser's localStorage. This may include provider information, endpoint/base URL, model, API key, and external AI consent state.

Generated summary content may also be stored locally for the relevant video/transcript generation.

TubeMind AI does not persist local transcript search queries through Chrome storage in the current implementation.

Sharing of Data

TubeMind AI does not sell user data.

Transcript-derived content is shared with an external AI provider only when the user has configured that provider, supplied the necessary credentials, granted external AI consent, and requests AI Summary generation.

Permissions

TubeMind AI requests only the permissions needed for its current functionality:

  • scripting — to read YouTube runtime caption metadata through Manifest V3 main-world execution;
  • tabs — to identify and coordinate with the active YouTube tab for transcript loading and timestamp navigation;
  • https://www.youtube.com/* host access — to run on YouTube pages, load transcript-related data, render the sidebar, and interact with the active YouTube video for timestamp navigation.

Remote Code

TubeMind AI does not download or execute remote JavaScript or WebAssembly code. The extension's executable code is packaged with the extension. Optional AI Summary requests send data to the user-configured provider as a service request; they do not load executable code into the extension.

Limited Use

TubeMind AI uses user data only as necessary to provide and improve its disclosed single purpose and user-facing features. TubeMind AI does not sell user data, does not use user data for advertising, and does not use user data to determine creditworthiness or for lending purposes.

Security

TubeMind AI is designed so that API keys are not exposed through public configuration, UI state, or diagnostic output. External AI requests are made only after explicit user configuration and consent.

Data Retention and Deletion

Locally stored AI configuration and generated summaries remain in the user's browser until they are changed or removed by the user, the extension, or browser storage controls. Data sent to an external AI provider is subject to that provider's own privacy and retention practices.

Changes to This Policy

If TubeMind AI's data-handling practices materially change, this Privacy Policy will be updated to reflect those changes.

Contact

For privacy or release-review questions, use the Chrome Web Store developer contact associated with TubeMind AI.
